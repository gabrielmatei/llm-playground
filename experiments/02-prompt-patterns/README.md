# Experiment 02: Prompt Patterns

This experiment demonstrates common prompt engineering patterns:
1. **Zero-Shot**: Direct queries.
2. **Few-Shot**: Providing examples.
3. **Chain-of-Thought (CoT)**: Step-by-step reasoning.
4. **Persona**: Adopting a character or role.

## Run
- Ensure `.env` is set up.
- Run: `pnpm exp:02`
